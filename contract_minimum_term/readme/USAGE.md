1. Create a contract from a template with a minimum term, or set the minimum
   term in the **Minimum Term** tab of the contract (or of the contract lines
   when the recurrence is managed at line level).
2. On the line, **Auto Renew** renews the minimum term when the contract is
   not terminated within the termination notice.
3. Once the start date is set, the end of the minimum term and the
   termination notice deadline are computed and displayed on the contract and
   its lines.
4. Click on **Terminate Contract**, set the date on which the termination was
   received: the earliest possible termination date is proposed.
5. A termination before this date is refused, except for the users of the
   group `Contract: Terminate Before Minimum Term`.
6. The same applies to stopping a single contract line. Cancelling a line is
   only possible as long as it has not started; a user of that group may also
   cancel a started line that was never invoiced.
