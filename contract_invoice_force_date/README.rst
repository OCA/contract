contract's recurring date.

Usage
=====

To use this module, you need to:

1. Go to *Accounting* > Customers/Vendors > Manually invoice contracts
2. In the popup, choose invoicing date to select contracts to invoice
3. If contracts are available to invoice, you can set **Date to set on
   Invoice** |img.png|
4. **Create Invoices**
5. The invoices are generated with the date chosen |img_1.png|
