This module allows to define an invoice day number on contract. This
number will be used as day for invoice dates.

**Table of contents**

.. contents::
   :local:

Use Cases / Context
===================

- Accountant users need to generate invoices a certain amount of time
  before invoice validation and final date in order to review them. Or
  under some agreements with customers, they need to get invoice date to
  be on a particular date. In order to do so, we introduce a day number
  to be used for the invoice date. e.g.: The invoices are generated
  every month on the first day with an invoice date on the 10th of that
  month.

Configuration
=============

- Go to Accounting > Customers/Suppliers > Contracts
- On a contract, you can define the day number you want generated
  invoices to have their invoice date. If a day number is lower than the
  next recurring invoice date day, the invoice date will take the next
  month day.
