#. Open a contract (*Contract > Customers/Suppliers > Contracts*).
#. Set the new *Analytic* field in the header, distributing across one or
   more analytic accounts/plans, same as you would on a contract line.
#. All existing contract lines are updated with that same analytic
   distribution. Any new line you add afterwards inherits it by default.
#. You can still override the analytic distribution of an individual
   line manually; it will not be touched again unless the header
   analytic distribution is changed once more.
#. On the related project's form, use the *Contracts* smart button to
   open every contract that has a line distributed to that project's
   analytic account.
