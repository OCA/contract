Glue module betweens product_contract that generate contracts from Sale
order, contract_fixed_discount that allows to manage discount with fixed
amount and sale_fixed_discount that allows to manage discount with fixed
amount.

So this module propagate the fixed discount defined on sale order line
to the fixed discount field on contract line.
