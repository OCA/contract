This module integrates HR employee management with the contract management system,
specifically designed for managing freelancer and contractor contracts.

Key Features:
* Links HR employees (freelance/contractor type) with contract management
* Automatically syncs employee information (department, job position) to contracts
* Provides dedicated views for managing freelancer/contractor contracts
* Adds contract management capabilities to employee records
* Supports contract creation and management for external workers

.. IMPORTANT::
   This is an alpha version, the data model and design can change at any time without warning.
   Only for development or testing purpose, do not use in production.
   `More details on development status <https://odoo-community.org/page/development-status>`_

Configuration
=============

Prerequisites:
* The module requires both 'contract' and 'hr_contract' modules to be installed
* Your user should have HR Contract Manager permissions to access contract management features

Configuration Steps:

#. Install the module from Apps menu
#. Ensure you have proper user permissions:

   * HR Contract Manager group for full contract management access
   * HR User group for basic employee management

#. Configure employee types in HR settings if needed
#. Set up departments and job positions for proper contract organization

User Permissions:
* HR Contract Manager: Full access to create, edit, and manage freelancer/contractor contracts
* HR User: Can view employee contracts but limited editing capabilities
* Regular users: Can view their own contract information if applicable

Usage
=====

#. Go to *Human Resources > Employees*.
#. Create or edit an employee with type "Freelance" or "Contractor".
#. In the employee form, you will see a "Contractor/Freelancer" button in the button box.
#. Click on the "Contractor/Freelancer" button to view/create contracts for this employee.
#. Alternatively, go to *Human Resources > Payroll > Contractor/Freelancer* to manage all freelancer contracts.
#. Create a new contract and select the employee (only freelance/contractor employees will be available).
#. The employee's department and job position will be automatically filled from the employee record.
#. Fill in the contract details including partner, products, and payment terms.
#. The contract will be linked to the employee and can be used for invoicing and contract management.
