This module extends ``Contract`` and delegates invoicing contracts to
jobs.

When invoicing a large number of contracts, the task is delegated to
jobs to avoid server time-outs.

This applies to:

- Auto invoicing (cron)
- Manual invoicing (wizard)

Use Cases / Context
===================

BUSINESS NEED:

- Invoicing a large number of contracts

USEFUL INFORMATION:

- Extends the module ``contract``

Configuration
=============

1. Go to Accounting > Configuration > Settings > Contract
2. **Invoicing Batch Size**

Usage
=====

Automated invoices are created in batch automatically.

For manually creating invoices in batch, go to:

1. Go to *Invoicing* or *Accounting* >

- Customers > **Manually Invoice Sale Contracts** or
- Vendors > **Manually Invoice Purchase Contracts**

2. Choose **Batch Create Invoices** |Manual Invoice Wizard|

See them in Job Queue > Jobs:

- *Automated/Manual Batch Invoice Contracts*
